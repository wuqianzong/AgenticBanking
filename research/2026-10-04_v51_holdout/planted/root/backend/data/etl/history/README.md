# Historical ETL Branches

These branches are preserved as provenance, not as supported rebuild paths.
Their original scripts retain historical relative-path assumptions and may need
an explicit, reviewed input/output configuration before being run again.

Use the active reconciliation and ingestion scripts in `../active/scripts/` for
the current RAG evidence contract. See `docs/etl/ETL_HISTORY_AND_ARTIFACT_GUIDE.md`
for branch lineage and the reason each historical branch was retired.
